          Servidores de comando recentes

          Um servidor de comando (C2) é o computador que um criminoso usa para controlar máquinas infectadas.

            Como manter atualizado

            Ver o passo a passo
            1. Deixe painel.html, coletar_dados.py e servidor.py na mesma pasta.
            2. pip install requests
            3. Para o ranking de países atacados, crie um token gratuito de leitura do Cloudflare Radar e rode export CLOUDFLARE_API_TOKEN=seu_token. Sem ele, o painel usa só servidores de botnet e falhas da CISA.
            4. python servidor.py e abra o endereço mostrado (no celular, use o IP do computador na mesma rede Wi-Fi).
            5. A página busca dados novos a cada 60 segundos e se redesenha sozinha.
            Fontes: CISA KEV, abuse.ch Feodo Tracker e Cloudflare Radar. São feeds públicos de ameaças, não uma visão completa de todos os ataques do mundo.
